# Robot autónomo para limpieza de alcantarillado

## Descripción

Este proyecto consiste en el diseño y simulación de un robot autónomo capaz de recorrer un sistema de alcantarillado, detectar residuos y obstáculos, y simular acciones de limpieza.

El proyecto será desarrollado utilizando Webots para la simulación del entorno 3D y Python para programar el comportamiento autónomo del robot.

## Problemática

La acumulación de residuos y sedimentos en los sistemas de alcantarillado puede dificultar el flujo del agua y aumentar el riesgo de obstrucciones y desbordamientos. La inspección y limpieza de estos espacios también puede presentar dificultades debido a las condiciones y el acceso limitado.

## Solución propuesta

Se propone desarrollar un robot autónomo que pueda desplazarse dentro de un escenario de alcantarillado, detectar posibles residuos u obstáculos mediante sensores, ejecutar una acción de limpieza simulada y registrar información sobre las zonas inspeccionadas.

## Tecnologías

* Webots
* Python

## Objetivo

Desarrollar una simulación funcional de un robot autónomo que permita demostrar el uso de sensores, programación, procesamiento de información y control de actuadores para realizar tareas de inspección y limpieza.
